# API

Full interactive documentation is auto-generated by FastAPI and served at `http://localhost:8000/docs` (Swagger UI) and `/redoc` whenever the backend is running — that is the authoritative, always-up-to-date reference. This file is a human-oriented map of the surface.

## Conventions

- All endpoints are prefixed `/api`.
- Authenticated endpoints require `Authorization: Bearer <access_token>`.
- Errors always take the shape:
  ```json
  { "error": { "code": "INVALID_STATE_TRANSITION", "message": "Human readable message" } }
  ```
- Role restrictions are enforced server-side (see `SECURITY.md`), not just hidden in the UI.

## Auth

| Method | Path | Notes |
|---|---|---|

## Lots & quality

| Method | Path | Role | Notes |
|---|---|---|---|
| POST | `/api/lots` | FPO_AGENT, ADMIN | aggregates contributors, sums quantity |
| GET | `/api/lots`, `/api/lots/{id}` | scoped by role | farmer sees only lots they contributed to; buyer only lots open-for-offers or later |
| POST | `/api/lots/{id}/collect` | FPO_AGENT, ADMIN | DRAFT → COLLECTED |
| POST | `/api/lots/{id}/screen` | FPO_AGENT, ADMIN | runs the local deterministic preliminary screen; COLLECTED → UNDER_ASSESSMENT |
| GET | `/api/lots/{id}/screening` | scoped | preliminary screen result |
| POST | `/api/lots/{id}/assessment` | ASSAYER, ADMIN | finalizes the authoritative physical assessment; UNDER_ASSESSMENT → ASSESSED |
| GET | `/api/lots/{id}/assessment` | scoped | finalized assessment |
| PATCH | `/api/lots/{id}/assessment/correct` | ASSAYER, ADMIN | the only way to change a finalized assessment; always audit-logged |
| POST | `/api/lots/{id}/open-for-offers` | FPO_AGENT, ADMIN | ASSESSED → OPEN_FOR_OFFERS |
| POST | `/api/uploads/lots/{id}/media` | any authenticated role tied to the lot | validated file upload |
